# Celebrity Insights — static site

Movie & celebrity news: Hollywood, Bollywood, music and trending stories.
Static site generated from the Celebrity Insights Blogger articles.

- Live site: https://mdsonetmia04-cmyk.github.io/celebrity-insights-static/
- Original blog (still live): https://thecelebrityinsights.blogspot.com/

## Design

Styled on the **Filmlane** movie-website template by
[codewithsadee](https://github.com/codewithsadee/filmlane) — free to use,
no license. The template's CSS/JS and layout patterns (hero, card grid,
filters, footer) were reused and rebranded for Celebrity Insights; all
FilmLane demo movies, posters and text were removed.

## Contents

- `index.html` — homepage: featured story + all 35 stories with label filters
- `2026/11/*.html` — one page per story (35)
- `about.html`, `sitemap.xml`, `robots.txt`
- `images/` — story images (AI-generated covers/posters, downscaled to 1200px)
- `assets/` — FilmLane CSS/JS + background images
